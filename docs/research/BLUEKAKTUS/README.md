# BlueKaktus Offering Research Notes

Date prepared: 2026-06-03

This folder documents the BlueKaktus public offering as described on the official BlueKaktus website, with additional apparel technology context where the site does not explicitly describe implementation details.

BlueKaktus positions itself as two connected operating stacks:

- An AI supply-chain platform for brands, retailers, and buying houses.
- An ERP + MES + AI platform for apparel manufacturers and factories.

The documents are written for Eratex product and engineering analysis. They are not implementation requirements for Eratex, and they should not be treated as verified internal BlueKaktus architecture. When a point is inferred from generic apparel planning or ERP/MES practice, it is labelled as interpretation.

## Evidence Stance

The documents use three evidence labels:

- Official: directly stated on a BlueKaktus page.
- Officially implied: implied by several official feature descriptions or module relationships, but not described as a formal architecture.
- Interpretation: generic apparel ERP, PLM, sourcing, planning, MES, or retail-system context added to explain how such a capability typically works.
